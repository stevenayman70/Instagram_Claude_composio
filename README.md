# Instagram_Claude_composio
ازاي تربط انستجرام و كلود
ربط Instagram بـ Claude عن طريق Composio (لتحليل المحتوى)
دليل سريع لربط حساب Instagram Business/Creator بتاعك بـ Claude، عشان تقدر تسحب بيانات الـ Reels (المشاهدات، الوصول، الإعجابات، التعليقات، المشاركات، الحفظ، مدة المشاهدة...) وتطلب تحليل أداء كامل بالرسومات البيانية.

المتطلبات قبل ما تبدأ
حساب Instagram من نوع Business أو Creator (مش حساب شخصي عادي) — الـ API مش بيدعم الحسابات الشخصية.
الحساب يفضّل يكون مربوط بصفحة Facebook (زي أي إعدادات Instagram Graph API عادية).
تكون داخل على Claude.ai (أو أي واجهة بتدعم MCP connectors).
خطوات الربط
1. افتح رابط الاتصال بـ Composio
استخدم الرابط ده:

https://connect.composio.dev/mcp
ده هيوديك لصفحة Composio بتاعة الاتصال بأدوات خارجية (Instagram من ضمنها).

2. اطلب من Claude يبدأ الربط
في المحادثة، اكتب حاجة زي:

"اربطني بـ Instagram من خلال Composio عشان أحلل الـ Reels بتاعتي"

Claude هيدور على الأداة المناسبة (instagram توولكيت) وهيجيبلك رابط تفويض (auth link).

3. سجّل دخول ووافق على الصلاحيات
افتح الرابط اللي هيظهرلك.
سجّل دخول بحساب Instagram/Facebook بتاعك.
وافق على الصلاحيات المطلوبة (قراءة بيانات الحساب والمنشورات والـ Insights).
4. تأكيد الاتصال
بعد ما توافق، Claude هيستنى شوية ثواني للتأكد إن الاتصال بقى Active. لو نجح، هتقدر تكمل على طول.

إزاي تطلب التحليل بعد الربط
بعد ما الاتصال يبقى شغال، تقدر تطلب من Claude حاجة زي:

"اسحب كل الـ Reels بتاعتي (تاريخ النشر، المدة، الكابشن، المشاهدات، الوصول، الإعجابات، التعليقات، المشاركات، الحفظ، متوسط وقت المشاهدة)، رتّبهم حسب معدل التفاعل، اعمل تحليل شامل، وارسملي كل الرسومات البيانية اللي محتاجها (اتجاه التفاعل بمرور الوقت، أفضل وأسوأ 10 ريلز، الأداء حسب الفئة، طول الفيديو مقابل التفاعل، هاشتاجات، إلخ) وقولي تشخيص للنمو وخطة عمل."

Claude هيستخدم أدوات Composio عشان:

يجيب بيانات الحساب (INSTAGRAM_GET_USER_INFO)
يجيب كل المنشورات/الريلز (INSTAGRAM_GET_IG_USER_MEDIA)
يجيب مقاييس الأداء لكل ريل (INSTAGRAM_GET_IG_MEDIA_INSIGHTS)
يجيب نمو المتابعين/الوصول على مستوى الحساب (INSTAGRAM_GET_USER_INSIGHTS)
وبعدين يبني لك تقرير كامل فيه: نظرة عامة على البيانات → تحليل مفصّل مع رسومات → تشخيص النمو → خطة تسويق وتوصيات.

ملاحظات مهمة
حدود البيانات: الـ Insights متاحة بس للمنشورات المنشورة خلال آخر سنتين.
حجم الداتا: لو حسابك جديد وعدد الـ Reels قليل، التحليل هيغطي كل الداتا المتاحة (مش شرط 30-50 بوست لو مفيش عدد كافي).
متغيرات مش متاحة دايمًا: بعض البيانات زي "عدد المتابعين الجدد لكل ريل" أو "اسم الصوت المستخدم" مش دايمًا بترجع من الـ API — لو حصل كده Claude هيقولك بوضوح إيه اللي متاح وإيه اللي مش متاح.
الأمان: الاتصال بيتم عن طريق OAuth رسمي من Instagram/Facebook — Claude مبيشوفش الباسورد بتاعك، بس بيقدر يقرا البيانات اللي وافقت عليها.
فصل الاتصال: لو عايز تلغي الربط في أي وقت، تقدر تدير الاتصالات من نفس صفحة Composio.
مثال سريع (Prompt جاهز)
"استخدم Composio MCP واربطني بحساب Instagram Business بتاعي، واسحب بيانات كل الـ Reels المتاحة، وابني لي تقرير أداء كامل فيه: جدول ملخص، ترتيب أفضل وأسوأ الريلز حسب معدل التفاعل، تحليل حسب الفئة والمدة والكابشن، heatmap لأفضل وقت نشر، funnel chart، ورسم بياني لنمو المتابعين، وفي الآخر تشخيص للنمو وخطة تسويقية لمدة 30 يوم."
