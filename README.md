# 📲 ربط Instagram بـ Claude عن طريق Composio
### دليلك السريع لتحليل أداء الـ Reels بتاعتك بالذكاء الاصطناعي 🤖📊

---

## 🎯 إيه اللي هتعمله بالدليل ده؟

هتربط حساب Instagram بتاعك بـ Claude، وبعدها تقدر تطلب منه:
- 📥 سحب بيانات كل الـ Reels (مشاهدات، وصول، إعجابات، تعليقات، حفظ...)
- 📈 تحليل أداء كامل مع رسومات بيانية
- 🧠 تشخيص للنمو + خطة تسويق جاهزة

---

## ✅ المتطلبات قبل ما تبدأ

| المطلوب | التفاصيل |
|---|---|
| 🏢 نوع الحساب | Instagram **Business** أو **Creator** فقط (مش شخصي) |
| 🔗 الربط | يفضّل الحساب يكون مربوط بصفحة Facebook |
| 💻 المكان | تكون داخل على Claude.ai أو أي واجهة بتدعم MCP |

> ⚠️ الحسابات الشخصية العادية مش مدعومة من الـ API خالص.

---

## 🔧 خطوات الربط

### 1️⃣ افتح رابط Composio
```
https://composio.dev/
```
ده هيوديك لصفحة الاتصال بالأدوات الخارجية، ومن ضمنها Instagram.

### 2️⃣ اطلب من Claude يبدأ الربط
اكتب في الشات حاجة زي:
> 💬 "اربطني بـ Instagram من خلال Composioعشان أحلل الـ Reels بتاعتي"

Claude هيدوّر على أداة Instagram المناسبة، وهيديك **رابط تفويض (auth link)**.
```
https://connect.composio.dev/mcp
```
طط
### 3️⃣ سجّل دخول ووافق ✅
- افتح الرابط اللي هيظهرلك
- سجّل دخول بحساب Instagram / Facebook بتاعك
- وافق على صلاحيات القراءة (بيانات الحساب، المنشورات، الـ Insights)

### 4️⃣ استنى التأكيد 🔄
Claude هيتأكد إن الاتصال بقى **Active** خلال ثواني، وبعدها تقدر تكمل على طول.

---

## 🚀 إزاي تطلب التحليل؟

بمجرد ما الاتصال يشتغل، اكتب لـ Claude حاجة زي:

> 💬 "اسحب كل الـ Reels بتاعتي (تاريخ النشر، المدة، الكابشن، المشاهدات، الوصول، الإعجابات، التعليقات، المشاركات، الحفظ، متوسط وقت المشاهدة)، رتّبهم حسب معدل التفاعل، اعمل تحليل شامل، وارسملي كل الرسومات البيانية المهمة، وقولي تشخيص للنمو وخطة عمل."

### 🛠️ الأدوات اللي Claude هيستخدمها تلقائيًا:
- 👤 `INSTAGRAM_GET_USER_INFO` → بيانات الحساب
- 🎬 `INSTAGRAM_GET_IG_USER_MEDIA` → كل المنشورات/الريلز
- 📊 `INSTAGRAM_GET_IG_MEDIA_INSIGHTS` → مقاييس الأداء لكل ريل
- 📈 `INSTAGRAM_GET_USER_INSIGHTS` → نمو المتابعين والوصول

### 📄 الناتج النهائي هيكون تقرير فيه:
1. 📋 نظرة عامة على البيانات
2. 🔍 تحليل مفصّل + رسومات بيانية
3. 🩺 تشخيص النمو (متسارع / ثابت / متراجع)
4. 🎯 خطة تسويقية وتوصيات عملية

---

## ⚠️ ملاحظات مهمة قبل ما تعتمد على النتائج

- ⏳ **حدود البيانات**: الـ Insights متاحة بس للمنشورات المنشورة خلال آخر سنتين
- 📉 **حجم العينة**: لو حسابك جديد وعدد الريلز قليل، التحليل هيغطي كل الداتا المتاحة (مش شرط 30-50 بوست)
- ❓ **بيانات مش متاحة دايمًا**: زي "متابعين جدد من كل ريل" أو "اسم الصوت" — لو مش موجودة، Claude هيقولك بوضوح
- 🔐 **الأمان**: الربط بيتم بـ OAuth رسمي — Claude مبيشوفش الباسورد، بس بيقرأ البيانات اللي وافقت عليها
- ❌ **إلغاء الربط**: تقدر تلغيه في أي وقت من نفس صفحة Composio
